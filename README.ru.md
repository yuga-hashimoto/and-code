**Запускайте ИИ-агентов для программирования локально на Android через нативный графический интерфейс — терминал не нужен.**

AndCode — это нативное Android-приложение с графическим интерфейсом, которое приносит ИИ-агентов для программирования на ваш телефон. Общайтесь с [OpenCode](https://github.com/sst/opencode), [Claude Code](https://github.com/anthropics/claude-code), [Google Antigravity](https://github.com/google-antigravity/antigravity-cli) и [OpenAI Codex](https://github.com/openai/codex) через интерфейс, рассчитанный на сенсорное управление — без терминала, без SSH и без ПК для работы на устройстве. Приложение запускает среды выполнения агентов через PRoot (на устройстве) или подключается удалённо к вашему существующему серверу OpenCode на ПК/Mac/Linux.

AndCode не связан, не одобрен, не спонсируется и официально не поддерживается OpenCode, Anthropic, Google или OpenAI. См. ## Поддерживаемые агенты

| Агент | На устройстве | Удалённый ПК | Статус |
|-------|:-------------:|:------------:|--------|
| [OpenCode](https://github.com/sst/opencode) | ✓ | ✓ | Стабильно |
| [Claude Code](https://github.com/anthropics/claude-code) | ✓ | — | Бета |
| [Google Antigravity](https://github.com/google-antigravity/antigravity-cli) | ✓ | — | Бета |
| [OpenAI Codex](https://github.com/openai/codex) | ✓ | — | Бета |

Агенты на устройстве работают внутри среды Linux через PRoot. OpenCode, Claude Code и Codex используют Alpine Linux; Google Antigravity дополнительно устанавливает rootfs Debian Bookworm рядом с Alpine, поскольку официальный бинарник `agy` слинкован с glibc.

## Возможности

- **Нативный интерфейс Android** — Интерфейс для агентов программирования, рассчитанный на сенсорное управление; для повседневной работы не нужны CLI или терминал
- **Среда выполнения на устройстве** — Alpine Linux, Git, bash, curl, ripgrep и агенты программирования автоматически устанавливаются на ваше Android-устройство через PRoot
- **Репозиторий и рабочая область** — Открывайте git-репозитории на устройстве, просматривайте дерево файлов и файлы с подсветкой синтаксиса
- **Файлы устройства** — Предоставьте доступ ко всем файлам, и весь телефон (`/sdcard`, SD-карты, USB-накопители) станет доступен для просмотра в выборе папки и для агента; файлы открываются на месте, а не копируются в приложение
- **Поддержка Git** — Просматривайте статус и diff в интерфейсе; для остальных операций Git используйте встроенный терминал среды выполнения
- **Просмотр diff** — Проверяйте изменения кода построчно перед принятием
- **Встроенный терминал** — Интерактивный shell (настоящий PTY) внутри среды на устройстве: потоковый вывод, stdin, Ctrl+C, цвета, и он открывается в той рабочей области, откуда вы пришли. Запущенные в нём dev-серверы (Vite, `python -m http.server`, …) отображаются в виде чипов, открывающих страницу во встроенном браузере. Полноэкранные программы вроде `vim` пока не поддерживаются
- **Значки pull request** — Открытые в чате pull request закрепляются над полем ввода с размером diff и статусом (черновик, открыт, конфликт, слит, закрыт); нажмите, чтобы открыть их на GitHub
- **Подтверждение инструментов** — Одобряйте или отклоняйте опасные операции инструментов
- **Управление сеансами** — Создавайте, возобновляйте, переименовывайте и удаляйте сеансы
- **Запланированные задачи** — Автоматически выполняйте запросы по разовому или повторяющемуся (cron) расписанию с историей запусков
- **Динамические модели** — Модели, провайдеры и агенты загружаются в реальном времени из подключённого экземпляра агента
- **Потоковая передача в реальном времени** — Ответы, выполнение инструментов и запросы на подтверждение в реальном времени через SSE
- **Структурированная временная шкала** — Сворачиваемые рассуждения, вызовы инструментов и вывод команд
- **Голос + слово активации** — Push-to-talk с распознаванием речи Android и обнаружением слова активации
- **Синтез речи** — Чтение ответов вслух
- **Цифровой помощник** — Регистрация как цифрового помощника Android по умолчанию (жест «домой» / свайп из угла)
- **Виджет на главном экране** — Отправляйте запрос прямо из лаунчера, не открывая приложение
- **Безопасное хранилище** — Учётные данные подключений шифруются с помощью Android Keystore
- **Локализованный интерфейс** — Английский, японский, китайский (упрощённый), русский, испанский, французский, португальский (Бразилия) и арабский; переключение в настройках

## Antigravity

Google Antigravity (`agy`) работает на устройстве в той же среде PRoot. В отличие от OpenCode и Claude Code, которые работают в Alpine Linux, Antigravity использует rootfs Debian Bookworm для совместимости с glibc официального бинарника CLI.

- **Вход через OAuth** — Аутентификация через URL в браузере + одноразовый код; учётные данные хранятся только внутри Linux rootfs (`~/.gemini`) и никогда в настройках Android
- **Выбор модели** — Каталог моделей в реальном времени, получаемый из авторизованного экземпляра `agy` (варианты Gemini, Claude и GPT-OSS)
- **Режимы разрешений** — Трёхуровневый контроль: Plan, Accept Edits и Full Access (`--dangerously-skip-permissions`)
- **Серверы MCP** — Прямое чтение и запись `~/.gemini/config/mcp_config.json` в том же формате, что и у официальной CLI
- **Запуск в песочнице** — Процесс на базе PTY с явной геометрией терминала; `AGY_CLI_DISABLE_AUTO_UPDATE=1` оставляет обновления под контролем приложения

## Codex

Codex CLI от OpenAI работает на устройстве в той же песочнице Alpine/PRoot, что OpenCode и Claude Code, и общается с приложением по протоколу JSON-RPC `app-server`.

- **Вход** — Аккаунт ChatGPT (через браузер) или ключ API OpenAI, в том же диалоге входа, что и у других провайдеров
- **Серверы MCP** — Управляются официальной подкомандой `codex mcp`, поэтому приложение никогда не редактирует `~/.codex/config.toml` вручную
- **Генерация изображений** — Изображения из встроенного инструмента `image_gen` отображаются прямо в чате
- **Установка** — Доступна из руководства по настройке или Настройки → Агенты → Codex; отдельный rootfs не нужен, так как бинарник Codex с musl работает непосредственно в общей среде Alpine

Подробности реализации см. в [docs/CODEX.md](docs/CODEX.md).

## Удалённый OpenCode

Помимо агентов на устройстве, AndCode может подключаться к OpenCode, запущенному на вашем ПК/Mac/Linux, как дополнительная возможность:

- **Удалённое подключение** — Подключение по LAN или Tailscale
- **Переключение среды выполнения** — Бесшовное переключение между локальным и удалённым выполнением даже посреди диалога (handoff)
- **Обнаружение** — Поиск ПК по QR-коду или mDNS (обнаружение в LAN без настройки)

## Экраны

| Экран | Описание |
|-------|----------|
| Чат | Главный экран и просмотр беседы — недавние сеансы, сворачиваемые рассуждения/инструменты, голосовой ввод, переключение модели, подтверждения, handoff |
| Рабочие области | Настройка локальной среды, подключения к ПК, рабочие папки, просмотр файлов, просмотр кода, встроенный терминал |

| Настройки | Агенты и провайдеры, GitHub, серверы MCP, видимость моделей, голос/TTS, цифровой помощник, язык |

## Быстрый старт

### Вариант A: на устройстве (ПК не нужен)

1. Установите APK из [Releases](https://github.com/yuga-hashimoto/and-code/releases/latest)
2. Откройте приложение → нажмите **Рабочие области** → **Это Android-устройство** → **Настроить на этом устройстве**
3. Дождитесь загрузки и установки среды выполнения (~2 мин при хорошем соединении)
4. Выберите агента программирования и начните чат

### Вариант B: удалённый ПК

1. Запустите OpenCode на ПК:

```bash
OPENCODE_SERVER_PASSWORD='your-strong-password' \
  opencode serve --hostname 0.0.0.0 --port 4096 --mdns
```

2. Установите APK на Android-устройство
3. Откройте приложение → **Рабочие области** → **Добавить подключение**
4. Введите IP-адрес ПК (или используйте **Поиск в LAN** / **QR-код** для автообнаружения)

```text
Name:     Mac mini
URL:      http://192.168.1.10:4096
Username: opencode
Password: your-strong-password
```

> Tailscale тоже работает: `http://100.x.y.z:4096` или `http://your-mac.tailnet-name.ts.net:4096`

### Настройка по QR-коду

Сгенерируйте QR-код на ПК:

```bash
npx qrcode "opencode://connect?name=Mac%20mini&url=http%3A%2F%2F192.168.1.10%3A4096&username=opencode&password=your-password&insecure=true"
```

Затем отсканируйте его в приложении через **Рабочие области** → **Добавить по QR**.

## Безопасность

- **Никогда** не открывайте порт 4096 напрямую в интернет
- Используйте LAN или Tailscale для подключения
- В публичных сетях используйте обратный прокси HTTPS
- Приложение никогда не одобряет опасные операции автоматически
- Открытый HTTP в LAN требует явного согласия для каждого подключения
- PRoot — это среда совместимости, а не полноценная песочница безопасности. Режимы полного доступа / обхода разрешений позволяют официальной CLI выполнять команды и редактировать файлы без запроса; приложение предупреждает перед их включением, но вам всё равно следует делать резервные копии важных файлов и направлять агента только на доверенные репозитории, запросы и серверы MCP
- QR-коды, созданные для потока `opencode://connect`, могут содержать пароль подключения в открытом виде — сканируйте только коды из доверенного источника и относитесь к напечатанному/показанному QR-коду так же, как к передаче этого пароля

## Среда выполнения на устройстве

Процесс настройки (запускается из «Рабочих областей»):

1. Проверяет нативный PRoot-раннер, встроенный в APK
2. Загружает minirootfs Alpine Linux с официального CDN
3. Загружает бинарник агента из GitHub Releases
4. Проверяет контрольные суммы SHA-256 для обоих
5. Распаковывает в приватный каталог приложения
6. Устанавливает Git, bash, curl, ripgrep и сертификаты CA внутри Alpine
7. Запускает сервер агента на `127.0.0.1:4097`
8. Переключает приложение на локальную среду выполнения

Закреплённые версии (обновляются через релизы приложения без изменения агента; см. [`local-runtime-manifest.json`](app/src/main/assets/local-runtime-manifest.json)):

- Alpine Linux 3.24.1
- OpenCode 1.18.5
- Google Antigravity CLI 1.1.7 (rootfs Debian Bookworm)
- Архитектуры: arm64-v8a, x86_64

## Handoff (переключение среды выполнения посреди диалога)

В меню заголовка чата → **Продолжить в другой среде выполнения** — приложение формирует запрос с кратким содержанием беседы и отправляет его выбранной среде, позволяя продолжить с того же места (например, начать на устройстве по дороге и продолжить на ПК дома).

## Подключение к OpenCode Desktop

Добавьте конфигурацию сервера в `~/.config/opencode/opencode.json`:

```json
{
  "server": {
    "port": 4096,
    "hostname": "0.0.0.0",
    "mdns": true
  }
}
```

Перезапустите настольное приложение, затем найдите его из Android-приложения через **Поиск в LAN**.

## Сборка из исходного кода

Требования: JDK 17, Android SDK, Python 3, доступ к сети (только для первой сборки)

```bash
./gradlew detekt spotlessCheck :app:lintGithubDebug :app:testGithubDebugUnitTest :app:assembleGithubDebug :app:assembleGithubRelease
```

Выходные APK:

```text
app/build/outputs/apk/github/debug/app-github-debug.apk
app/build/outputs/apk/github/release/app-github-release-unsigned.apk
```

Установка на устройство:

```bash
adb install -r app/build/outputs/apk/github/debug/app-github-debug.apk
```

## Правовая информация и стороннее ПО

- **Официальные CLI работают на устройстве.** OpenCode, Claude Code, Google Antigravity и OpenAI Codex — это официальные немодифицированные бинарники соответствующих проектов, загруженные из официальных каналов распространения и запускаемые в среде Linux PRoot на вашем устройстве (или, для OpenCode, на вашей собственной машине ПК/Mac/Linux). AndCode не форкает, не патчит и не переписывает логику их агентов.
- **Вы используете собственный аккаунт или доступ к API.** AndCode не продаёт, не перепродаёт и не предоставляет доступ к Claude, Antigravity, Codex, моделям OpenCode или GitHub. Вы аутентифицируетесь своим аккаунтом или конфигурацией провайдера в соответствии с действующими условиями обслуживания этого провайдера.
- **AndCode не передаёт запросы или токены через собственные серверы.** Не существует бэкенда AndCode, через который проходят запросы, файлы или OAuth-токены. Запросы идут напрямую от CLI на устройстве (или сервера OpenCode на ПК) к настроенному вами провайдеру. См. [docs/AUTHENTICATION_AND_DATA_FLOW.md](docs/AUTHENTICATION_AND_DATA_FLOW.md).
- **OAuth-токены не используются повторно между инструментами.** Claude Code, Antigravity и Codex хранят собственные учётные данные OAuth внутри Linux/Debian rootfs так, как это обычно делает их официальная CLI; AndCode никогда не копирует их в настройки Android-приложения, хранилище учётных данных другого агента или во внешний сервис.
