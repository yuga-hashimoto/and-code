AndCode

Run coding agents locally on Android with a native GUI. No terminal. No PC required.

↓ Download APK View on GitHub

Features

📱

Native Android GUI

Touch-first interface built for Android. No terminal, no CLI — just tap, talk, and code.

⚡

On-Device Runtime

Full Alpine Linux environment running coding agents locally on your phone via PRoot.

🤖

OpenCode

Run OpenCode locally on-device or connect to a remote instance on your PC/Mac/Linux.

🧠

Claude Code

Run Claude Code directly on your Android device with the same native GUI.

🚀

Google Antigravity

Run Google's Antigravity CLI on-device, with OAuth sign-in and live model selection.

📂

Repository & Workspace

Open and work within git repositories on-device with full workspace management.

🌿

Git Support

Stage changes, view diffs, commit, and manage branches — all from the GUI.

📋

Diff Viewer

Review code changes inline before accepting. Know exactly what your agent is modifying.

🔗

Pull Request Badges

PRs opened in a chat stay pinned above the composer with diff size and state — tap to open on GitHub.

✅

Tool Approvals

Approve or reject dangerous operations. No auto-approve — you stay in control.

💬

Session Management

Create, resume, rename, and delete sessions. Switch agents and models on the fly.

⏰

Scheduled Tasks

Run prompts automatically on a one-time or recurring (cron) schedule, with run history.

🎙️

Voice + Wake Word

Push-to-talk voice input with wake word detection. Use it as your Android digital assistant.

🖥️

Remote OpenCode

Connect to OpenCode on your PC/Mac/Linux over LAN or Tailscale. Seamless handoff between devices.

Get Started in Minutes

1

Download the APK

Grab the latest release from GitHub. Supports arm64 and x86_64 devices.

2

Set up your runtime

Tap to install the on-device runtime (~2 min) or connect to your PC's agent server via LAN/Tailscale.

3

Start coding

Chat with your AI coding agent, approve tool operations, review diffs — all from your phone.
